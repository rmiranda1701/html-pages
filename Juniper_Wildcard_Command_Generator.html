Juniper Wildcard Command Generator

Generate multiple interface commands from wildcard patterns

Use brackets for ranges: ge-0/0/[0-5], xe-0/0/[10-20], et-0/0/[0,2,4]
Examples:
ge-0/0/[0-10] → Generates ge-0/0/0 through ge-0/0/10
xe-0/0/[0,2,4,6] → Generates xe-0/0/0, xe-0/0/2, xe-0/0/4, xe-0/0/6
et-0/0/[48-51] → Generates et-0/0/48 through et-0/0/51
Enter the command portion after "interfaces {interface}"
